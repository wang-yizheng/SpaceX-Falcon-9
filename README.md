# SpaceX-Falcon-9
SpaceX Falcon 9 是一款专为商业航天和政府任务设计的可重复使用运载火箭，凭借革命性的回收技术、高可靠性和低成本优势，重新定义了现代航天发射标准。核心性能参数：采用两级设计，全长 70 米，直径 3.7 米，起飞质量约 549 吨；搭载 9 台 Merlin 1D 发动机，海平面推力达 7,607 kN，真空推力达 8,227 kN；近地轨道运载能力 22.8 吨，地球同步转移轨道运载能力 8.3 吨；支持单星、多星和载人任务，已成功执行超过 300 次发射。革命性回收技术：一级火箭配备栅格翼和着陆腿，可在海上驳船或陆地着陆场精准回收；通过多次复用，大幅降低发射成本，单次发射费用降至约 6,700 万美元；回收后的火箭经过检修和测试，可再次执行任务，最快复用间隔仅 21 天。智能
